## 一、汇率牌价表

把每个可兑换 SKU 当成一个 `POINT/CNY` 货币对，汇率 = 现金价值 ÷ 所需积分。

```
                         POINT / CNY  EXCHANGE BOARD
                    生成时间 2026-10-15 22:25:05    样本 7 个在售商品

   #  商品                            积分   现金价   汇率(元/分)   反牌价(分/元)
  ------------------------------------------------------------------------
   1  6.9元香芋派/菠萝派任选             50    6.90      0.1380          7.2
   2  6.9元可乐麦炫酷                   50    6.90      0.1380          7.2
   3  10.9元指定小食任选                100   10.90      0.1090          9.2
   4  10.9元指定小食任选                200   10.90      0.0545         18.3
   5  17.9元板烧可乐组合                500   17.90      0.0358         27.9
   6  16.9元麦辣可乐组合                500   16.90      0.0338         29.6
   7  21.9元巨无霸可乐组合              800   21.90      0.0274         36.5
  ------------------------------------------------------------------------

  最优牌价   0.1380 元/分   <- 6.9元香芋派/菠萝派任选（50 分）
  最差牌价   0.0274 元/分   <- 21.9元巨无霸可乐组合（800 分）
  中位牌价   0.0545 元/分
  极    差   5.04 x   （同样 1 积分，选对选错价值差 5.04 倍）
```

**同样是 100 积分**：换香芋派值 ¥13.80，换巨无霸可乐组合只值 ¥2.74。

> **程序员节彩蛋**：商城里那套罗技键鼠要 **6666 积分**。
> 按在售中位牌价 0.0545 元/分算，这 6666 分本可以换到约 **¥363** 的商品；
> 而键鼠套装的公开市场参考价约 **¥149**。
> 也就是说，用它等于拿 ¥363 换了 ¥149——**打了 4 折出手**。
> 情怀归情怀，汇率归汇率。

## 二、抽奖 EV：该不该赌？

单次消耗 **24 积分**，奖池 10 个奖品。问题来了：这 24 分，抽奖还是直接兑换？

```
                             LOTTERY EV DESK
                      麦麦积分抽奖 · 单次消耗 24 积分

  奖品                      估值(元)  取值依据
  --------------------------------------------------------------
  下单立减3元券                3.00  券面直减
  下单立减2元券                2.00  券面直减
  下单立减1元券                1.00  券面直减
  麦辣三件套5折券             13.45  以 26.9 元三件套为基准
  板烧三件套5折券             12.45  以 24.9 元三件套为基准
  双层鳕鱼三件套6折券          9.96  以 24.9 元三件套为基准
  甜辣小食组合5折券            7.95  以 15.9 元组合为基准
  小食四件套5.5折券           13.46  以 29.9 元四件套为基准
  麦旋风5折券                 4.50  以 9 元麦旋风为基准
  30积分                     1.64  按中位汇率 0.0545 元/分 折算
  --------------------------------------------------------------

  期望价值 EV          6.94 元 / 次
  每积分回报(抽奖)    0.2892 元/分
  每积分回报(兑换)    0.0545 元/分
  24 积分兑换等价     1.31 元

  >>> 结论：抽奖更划算（每积分回报是直接兑换的 5.31 倍）
  >>> 安全边际：抽奖的每积分回报要跌到当前的 18.8% 以下，直接兑换才会反超
  >>> 前提：官方未公布中奖概率，以上按等概率假设计算

  蒙特卡洛同成本对比：
    抽 10000 次，共消耗 240000 积分
    -> 抽奖所得     69200.42 元
    -> 直接兑换     13080.00 元
    -> 净  差       56120.42 元
```

**即使官方概率严重倾斜，结论也很难被推翻**——抽奖的领先优势有 5 倍以上的安全垫。

## 我们做对了什么

| | 常见积分工具 | mcd-point-fx |
|:---|:---|:---|
| 视角 | 记账：我有多少分、能换啥 | 定价：每一分**值多少钱** |
| 核心指标 | 积分余额 | **汇率（元/分）** |
| 抽奖 | 有就抽，看运气 | 算 EV，给安全边际 |
| 数据依赖 | 需要你的历史订单 | **只用公开数据**，零历史也能跑 |
| 门槛 | 要配 Token 才能试 | **零 Token 直接跑** |
| 依赖 | 一堆第三方库 | **0 个**，纯标准库 |

### 三个刻意的取舍

1. **默认只统计在售商品。** 第一版把已下架的「1 积分限时兑换」算了进去，
   得出「极差 621 倍」这种离谱数字。已下架的历史活动不能和当前商品同台比较，
   所以我们改成在售口径，并加了 `test_spread_is_credible` 防回归。

2. **不臆造价格。** 名称里没标现金价的商品（如「麦麦脆汁鸡两件套」）直接排除，
   不猜、不编。宁可少几个样本，也不污染结论。

3. **诚实标注假设。** 官方没公布中奖概率，我们就明说按等概率算，
   并给出"要跌到多少才不成立"的敏感性分析，而不是假装精确。

## 架构

```
mcd-point-fx/
├── demo.py                   # 一键演示，零 Token 可跑
├── mcd_point_fx/
│   ├── rate.py               # 汇率引擎：货币对定价、牌价表、最优兑换
│   ├── ev.py                 # EV 引擎：奖池解析、期望值、蒙特卡洛
│   ├── mcp_live.py           # 实时接入 MCP（标准库 urllib，兼容 JSON/SSE）
│   ├── snapshot.py           # 快照加载与在售判定
│   └── cli.py                # 命令行：rate / ev / best
├── data/snapshot.json        # 真实抓取的数据快照
└── tests/test_core.py        # 10 项单元测试
```

数据流：

```
   mall-points-products            query-lottery-info
            │                              │
            ▼                              ▼
    ┌───────────────┐            ┌───────────────┐
    │  汇率引擎      │            │   EV 引擎      │
    │  POINT/CNY    │            │  期权定价      │
    └───────┬───────┘            └───────┬───────┘
            └──────────► 联合结论 ◄───────┘
                  抽奖还是兑换？
```

## 数据来源与口径

- 数据来自 [麦当劳中国 MCP Server](https://github.com/M-China/mcd-mcp-server)（`https://mcp.mcd.cn`）。
- 现金价取自商品名称中的官方标注价；未标注价格的商品不参与定价。
- `point = 0` 的派对 / 品鉴会 / 读书会属于现金售卖，不构成货币对，已排除。
- 折扣券价值以菜单公示基准价估算，随门店与时段可能浮动。
- **官方未公布中奖概率，EV 基于等概率假设计算**，实际收益以官方规则为准。

> 本项目为麦当劳程序员节创意开发大赛参赛作品，由参赛者独立开发，**非麦当劳官方产品**。
> 输出仅供参考，不构成消费建议；餐品、价格与供应状态以麦当劳官方渠道实时结果为准。
